# Age of Empires 4 Strategy Toolkit — feature reference

Civilization notes, build orders, and match plans form the core of Age of Empires 4 Strategy Toolkit. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Civilization notes | A dedicated section for civilization notes and the configuration details associated with that area. |
| Build orders | A dedicated section for build orders and the configuration details associated with that area. |
| Match plans | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
